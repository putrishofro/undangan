Generator Tautan Undangan per Tamu

Alat bantu lokal (tidak perlu diunggah ke GitHub) untuk membuat tautan undangan yang sudah berisi nama masing-masing tamu, lalu membagikannya lewat WhatsApp. Simpan file ini di komputer Anda dan buka langsung di browser kapan saja.

Isi dengan alamat yang muncul setelah Anda mengaktifkan GitHub Pages (lihat README §5).
Format: Nama saja, atau Nama, nomor WhatsApp (pakai kode negara tanpa tanda + atau 0 di depan, misalnya 62 untuk Indonesia) jika ingin tombol kirim WhatsApp langsung aktif.
Belum ada tautan dibuat. Isi daftar tamu di atas lalu klik "Buat Tautan".
